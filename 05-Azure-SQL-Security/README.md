# AZURE-SQL-DATABASE-LAB
Securing Azure SQL Database. Configured Microsoft Defender for SQL, performed Vulnerability Assessments, implemented Data Discovery &amp; Classification, enabled SQL Auditing, and explored Azure SQL security monitoring and threat protection features.

##Overview:

The lab focuses on implementing security controls for Azure SQL Database, including enabling Microsoft Defender for SQL, performing vulnerability assessments, classifying sensitive data, and configuring auditing. These features help organizations protect database resources, detect threats, meet compliance requirements, and monitor database activity.
(The project was completed as part of hands-on preparation for the AZ-500: Azure Security Engineer Associate certification).

Lab Summary

In this lab, I learned how to secure Azure SQL Database by implementing key security and monitoring features available in Azure. The lab focused on protecting sensitive data, identifying security risks, and monitoring database activity to support compliance and threat detection.

Key Concepts Covered
Microsoft Defender for SQL

Configured and explored Microsoft Defender for SQL to help identify potential threats and vulnerabilities affecting Azure SQL Database resources. This service provides security recommendations, threat detection, and continuous monitoring to improve the security posture of database environments.

Vulnerability Assessment

Learned how to perform vulnerability assessments to identify security weaknesses, misconfigurations, and deviations from security best practices. Vulnerability assessments help administrators prioritize remediation efforts and maintain secure database configurations.

Data Discovery and Classification

Used Azure SQL's data classification capabilities to identify and label sensitive information stored within the database. This feature assists with data governance, regulatory compliance, and the protection of confidential information by categorizing data based on its sensitivity.

SQL Auditing

Configured auditing to track database activities and generate audit logs for monitoring and compliance purposes. Auditing enables organizations to record access attempts, data modifications, and other database events for investigation and reporting.

Security Monitoring and Compliance

Explored how Azure security services can be used to monitor database environments, review security recommendations, and maintain compliance with organizational and regulatory requirements.
